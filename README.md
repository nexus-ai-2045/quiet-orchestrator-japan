# 一枚設計｜静かなオーケストレーターとしての日本

> **位置づけ**: ハッカソン応募候補の社会シミュレーション仮説。日本政府の公式方針、将来予測、特定国への攻撃帰属、外交提言ではない。2026年8月23日時点の公開情報を危険の初期条件に使い、架空の複合危機を比較実験する。

## 公開根拠の階層

概念の公開原典は、ハッカソン公式サイトからリンクされる片山俊大氏の「メタ安全保障」構想ペーパー（Version 1.0）に限定する。

1. [AIエージェント社会シミュレーションハッカソン Vol.2 公式サイト](https://hackathon.automata-lab.jp/)
2. [メタ安全保障 構想ペーパー（公式サイト掲載PDF）](https://prtimes.jp/a/?f=d80352-184-caedebb354dd205d5811c599da74761b.pdf)

政府・公的機関のURLは、シナリオの現実性、領域名、各組織の公開された役割を確認するための参照資料であり、メタ安全保障の概念原典ではない。「公式準拠」は公式方針への賛同や実際の指揮系統の再現を意味しない。参照先は[公式URL台帳](official-sources.md)に分離する。

## 目的

日本は、米中対立の最前線にいる利害当事国でありながら、**海洋安全保障とサイバー安全保障の間を走る連鎖**を、宇宙・電磁波、経済安全保障、情報・外交の回線で束ね、戦争か事故か分からない複合危機を武力衝突へ転化させないオーケストレーターになれるか。

日本を中立な一人の仲裁者として置かない。官邸、外務、防衛、海上保安、沖縄、研究機関、企業が異なる目的を持つ「内部ネットワーク」として表現し、その内部調整が成立した場合だけ対外的な調整能力が生まれる。

## 一枚の結論

この作品で検証する「静かなオーケストレーター」は、会議の議長でも世界政府でもない。日本が前面で解決案を命令するのではなく、対立する主体が自分の判断権を残したまま協調できるよう、次の5機能を提供する役割である。

| 機能 | 日本が静かに行うこと | 成功の観測 |
|---|---|---|
| 翻訳 | 軍事、外交、海保、企業、研究者、AIの異なる言葉を接続する | 同じ主張の意味と確信度を主体間で比較できる |
| 検証 | 生データを奪わず、出所・反証条件付きの証拠パケットを作る | 米中を含む複数主体が最低限の事実を共有する |
| 可逆化 | 即応を放棄せず、相互停止・限定復旧・共同調査へ分解する | 不可逆な軍事行動までの時間が延びる |
| 複線化 | 公開、日米、日中、技術、多国間の回線を使い分ける | 一つの回線や一人の仲裁者が止まっても協調が残る |
| 共同所有 | 第三国、大学、通信、海運、保険、エネルギーを提案者にする | 「日本案への服従」でなく、各主体の利益として出口が維持される |

成功とは日本の発言力や名声が上がることではない。**日本が目立たなくても検証と撤退経路が残り、日本が抜けても協調が継続すること**を成功とする。逆に、監視の集中、機密漏洩、日本への依存、同盟の空洞化を生むなら、この構想は失敗である。

## できること

- 同じ危機と真因seedを、ブロック分断、同盟代理、単独仲裁、網状調整、調整崩壊の5条件で比較する。
- 確認済み事実、未検証主張、推論、提案を分け、攻撃帰属の確信度がどう伝播するか追跡する。
- 公開、日米、日中、技術検証、多国間の回線を分け、情報共有の便益と漏洩・依存のコストを同時に表示する。
- 武力衝突だけでなく、通信、港湾、海運、保険、エネルギー、住民不安へ連鎖が飛び移る位置を可視化する。
- 「日本なら成功する」という結論を埋め込まず、日本型調整が失敗する条件も同じ指標で反証する。

## 領域を固定する

ハッカソン上の二つの入力領域を、次のように固定する。

| 区分 | 本作で扱う範囲 |
|---|---|
| 入力領域1：海洋安全保障 | 海上法執行、船舶接触、シーレーン、港湾、海底ケーブルの物理的保全 |
| 入力領域2：サイバー安全保障 | 重要インフラ障害、インシデント対応、技術的検証、攻撃帰属の確信度 |
| 公式上の隣接領域 | 宇宙・電磁波（通信・測位）、経済安全保障（物流・エネルギー・保険）、情報・外交 |
| 本repo固有の観測系 | 物理／経済・産業／認知・文化の三相。政府の公式分類ではなく、連鎖を見るための実験上の座標系 |

宇宙、エネルギー、AI、研究機関を別々の入力テーマへ増やさない。それらは、海洋事象とサイバー事象の間で証拠、能力、損失、物語を運ぶ「接続ノード」として登場させる。

## 現実の出発点

公開情報から、次の脆弱性は同時に存在すると確認できる。個別の事実は、複合攻撃や差し迫った戦争を証明しない。

- 2024年、中国海警局船が尖閣諸島周辺の接続水域で確認された日数は過去最多の355日だった（[E-01](evidence.md#e-01-東シナ海の常態的接触)）。
- 2024年度の緊急発進は704回で、中国機464回、ロシア機237回だった（[E-02](evidence.md#e-02-日本周辺空域の継続的活動)）。
- 2026年6月には、中露爆撃機などによる日本周辺の長距離共同飛行が10回目として確認された（[E-03](evidence.md#e-03-中露の共同活動)）。
- 重要インフラへのDDoS、情報窃取、ランサムウェア被害が現実に観測されている（[E-04](evidence.md#e-04-重要インフラとサイバー脅威)）。
- 2024年度のエネルギー自給率は16.4%、海上輸送は貿易量の99.6%、海底ケーブルは国際通信の99%を担う（[E-05](evidence.md#e-05-エネルギー輸入依存)、[E-06](evidence.md#e-06-海上輸送依存)、[E-07](evidence.md#e-07-海底ケーブル依存)）。
- 通信・測位衛星は生活と防衛の双方に不可欠で、宇宙・サイバー・電磁波・認知を分離できない（[E-08](evidence.md#e-08-宇宙通信測位への依存)、[E-09](evidence.md#e-09-情報戦と領域横断性)）。

## 単一シナリオ：南西諸島72時間複合危機

台湾周辺の大規模演習中、尖閣周辺で中国海警船、日本の巡視船、民間船が接触する。直後に沖縄方面の海底ケーブル障害、港湾・金融へのDDoS、測位異常、「日本側が先に発砲した」とする真偽不明映像、米国からの支援要請、船舶保険料の上昇、北朝鮮のミサイル発射が重なる。

真因はワールドエンジンだけが持つ。統合的な威圧、偶発事故と便乗攻撃、第三国の扇動、無関係な障害の同時発生などをseedで切り替える。各エージェントは断片的な観測しか持たず、**検証前の攻撃帰属が政策決定を先回りすること**を一つの協調失敗として追う。

観測する一本の連鎖は、**海上接触（物理）→ 攻撃帰属と同盟要請（認知・政治）→ 通信・港湾・保険の停止（経済・産業）→ 住民不安と偽情報（認知・文化）→ 軍事的即応（物理）**。介入点は、物理事象が攻撃物語へ変わる結節と、その物語が不可逆な軍事行動へ変わる結節である。

## 登場エージェント

日本だけを細かく、米中を一人格にしない。公開された組織役割を参照し、同じ国内でも「政治調整」「外交」「軍事」「海上法執行」「技術対応」「民間運用」が異なる情報と権限を持つようにする。

| 国・系統 | 論理エージェント | 守りたいもの／矛盾 |
|---|---|---|
| 日本 | 官邸調整、外務、防衛、海上保安、沖縄・民間、独立検証 | 同盟・主権・住民保護・証拠保全を同時に満たせない |
| 米国 | NSC政治調整、INDOPACOM・在日米軍、国務省、サイバー対応連合、民間事業者 | 同盟の即応、能力秘匿、外交的出口、技術的確信度が一致しない |
| 中国 | 中央政治調整、東部戦区モデル、海警、外交部、サイバー技術対応、国有・民間事業者 | 主権主張、軍事的警戒、海上法執行、対外説明、サービス継続が一致しない |
| 多国間 | 第三国・国際機関連合 | 米中いずれにも従属せず、検証と出口の共同所有を保つ |

米国の「サイバー対応連合」はCISA、FBI、NSA、国防機関の公開上の分担を一つの論理ノードへ圧縮したもので、実在する単一組織ではない。中国の「中央政治調整」と「東部戦区モデル」も公開情報から作る抽象役割であり、非公開の意思決定や実際の将来行動を断定しない。

## 日本が使うオーケストレーション

1. **抑止**: 日米連携と防護態勢を維持し、一方的行動のコストを示す。
2. **検証**: 生データを全面公開せず、出所・確信度・反証条件を持つ共通証拠パケットを作る。
3. **出口**: 中国が敗北宣言をせず行動を縮小でき、米国も抑止を損なわない相互措置を設計する。
4. **利害接続**: 第三国、通信、海運、保険、エネルギー、大学を巻き込み、協力の便益と単独行動の損失を増やす。
5. **表裏の分離**: 公開声明、日米同盟回線、日中回線、技術検証室、多国間回線を使い分け、発言の矛盾と漏洩リスクを管理する。

日本は命令しない。異なる主体が自分の判断権を残したまま、少なくとも一つの共有事実と一つの可逆的行動へ合意できる状態を作る。

## 比較実験

| 条件 | 日本の行動 | 検証すること |
|---|---|---|
| A ブロック分断 | 日米と中国が別々に判断 | 誤認と自己強化がどこまで連鎖するか |
| B 同盟代理 | 日本が米国判断をそのまま実行 | 初動の速さと対中回線喪失の交換条件 |
| C 単独仲裁 | 日本が米中の間へ直接入る | 単一障害点化と「中立」への不信 |
| D 網状調整 | 日本内部と第三国・科学・企業を編成 | 非中立な当事国でも出口を作れるか |
| E 調整崩壊 | 省庁対立、異論圧縮、情報漏洩が発生 | 「日本なら成功する」という結論の埋め込み防止 |

## 評価と反証

単一の総合点で勝者を決めず、武力衝突、住民・インフラ被害、誤認訂正時間、日米信頼、中国の検証参加、第三国の自律性、過剰開示、物流・エネルギー継続、調整ノード依存を並べる。

次なら中心仮説を棄却・縮小する。

- Dだけに真因、追加情報、強い権限を与えなければ勝てない。
- 中国を非合理、米国を常に正確、日本を常に善意として描くほど成績が良くなる。
- 日本内部を一枚岩にした方が常に成功し、組織間調整を表現する意味がない。
- 日本の属性を外しても同じ結果となり、汎用的な危機協調プロトコルに還元される。
- seed、モデル、プロンプトを変えると結論が反転し、再現可能な傾向がない。

## 制約

- 現段階は設計であり、実行結果、性能、再現性はまだない。
- 公開情報には発表主体の視点、非公開情報の欠落、更新差があり、現実を完全には表さない。
- 論理エージェントは公開役割の抽象であり、実在組織の内部意思決定や将来行動を再現しない。
- LLMの出力はモデル、prompt、言語、初期信頼に依存するため、複数条件で感度を測る必要がある。
- 本作を現実の攻撃帰属、軍事的作戦立案、外交・防衛政策の採否へ直接使用しない。

## 最小デモ

同じ72時間をA〜Eで反復する。18の論理エージェントを定義し、各ターンで事件に関係する8〜10主体だけを起動する。1画面に「確認済み事実／未検証主張／各主体の信念」「公開・非公開の通信網」「三相をまたぐ連鎖」「不可逆行動までの残り時間」「指標のPareto比較」を表示する。観客が見るのは日本の勝利ではなく、**どの接続が誤認を止め、どの接続が新たな依存や漏洩を生んだか**である。
