# デザインシステム

## 方向性

危機を煽る軍事司令室ではなく、公共インフラの検証室を表現する。中心は2026〜2045年の接続網で、「終末の1ヶ月」は二次的な耐久試験として扱う。

## トークン

| 役割 | 値 | 用途 |
|---|---|---|
| 背景 | `#06131e` | 全体の静かな濃紺 |
| 基本面 | `#0a1c29` | 操作面と情報面 |
| 境界 | `#294454` | 細い構造線 |
| 主要文字 | `#e8f1f4` | 見出しと重要値 |
| 補助文字 | `#91a9b5` | 注記と単位 |
| 検証 | `#68d6dc` | 共有済み能力と選択 |
| 相互運用 | `#65c59b` | 継続可能な接続 |
| 未解決 | `#e0a14e` | 依存、待機、提案 |
| 不可逆リスク | `#e36c5c` | 断定、集中、危険境界 |

本文は日本語UI向けのシステムサンセリフ、年・指標・主体IDは等幅フォントを使う。意味のない装飾アイコンは置かない。

## 主要コンポーネント

| コンポーネント | 状態 | アクセシビリティ |
|---|---|---|
| 戦略時間軸 | 経過、現在、未到達、節目 | 現在年へ `aria-current="step"` |
| 年間アクション | 通常、hover、選択 | `button` と `aria-pressed` |
| 主体ノード | 通常、接続形成、選択 | React Flowの選択可能ノード |
| 指標 | 能力、リスク | ラベルと数値を色に依存せず併記 |
| 比較ダイアログ | 閉、開 | `role="dialog"` と明示的な閉じる操作 |
| 状態通知 | 更新、試験、リセット | `aria-live="polite"` |

中央の接続網を守り、常時表示する周辺UIは左右1面ずつに制限する。狭い画面では主体、ネットワーク、詳細の順へ縦積みする。非本質的な動きは `prefers-reduced-motion` で停止する。

選択済みの視覚仕様は[コンセプト画像](design/selected-ui-concept.png)、現在の実装画面は[終末の1ヶ月版プレビュー](images/simulator-preview-one-month.jpg)を参照する。コンセプト画像内の「72時間」は初期案の履歴であり、現在の期間正本はADR-0007の30日間である。
