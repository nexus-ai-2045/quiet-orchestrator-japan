# ADR-0006｜接続を状態化し、因果レジャーを正本にする

- status: accepted
- date: 2026-08-24

## 文脈

現在のMVPは、5つの施策を全体指標へ反映できる。一方、接続線は固定され、成熟度は主に年数で描画されるため、「誰と誰の連携が、なぜ変化したか」を説明できない。アクターを選択しても、固有の接続目的や施策効果は変わらない。

このままでは、オーケストレーションを扱う作品でありながら、ネットワーク自体がシミュレーション状態になっていない。

## 判断

各接続を、成熟、信頼、検証合意、相互運用、共同所有、依存、代替経路を持つ状態オブジェクトへ移行する。

年次施策は、全体指標を直接変更するだけでなく、対象接続へイベントを発生させる。イベントは変更前、変更後、理由、施策、主体、年を因果レジャーへ追記する。全体指標と終末の1ヶ月の結果は、この接続状態とイベントから集約する。

UIの線の太さ、色、破線、アニメーションは、年数や固定indexではなく接続状態から導出する。

## 帰結

- 同じ施策でも投資先によって結果が変わる。
- 危機結果から、寄与・阻害した接続を説明できる。
- 状態量とログが増え、テストfixtureとmigrationが必要になる。
- 係数の恣意性が接続単位で可視化されるため、根拠・感度分析がより重要になる。

## 非採用

- 接続線を表示専用のままにする: 因果を説明できないため採用しない。
- LLMの発話から接続状態を直接変更する: 再現性と権限境界を失うため採用しない。
- 国単位の好戦性・善意スコアで差別化する: ステレオタイプを埋め込むため採用しない。
