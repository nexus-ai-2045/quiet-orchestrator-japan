# ADR-0003: 静的・ローカルファーストWebアプリにする

- 状態: accepted
- 日付: 2026-08-24

## 文脈

ハッカソン審査と公開レビューでは、認証や外部APIなしに作品の中心ループを再現できる必要がある。機密・個人情報・外部送信も避けたい。

## 判断

React 19、Vite 6、React Flowで静的Webアプリを構成する。状態はブラウザ内にだけ保持し、バックエンド、認証、テレメトリ、ライブLLM APIをMVPへ入れない。

## 帰結

- `npm install` と `npm run dev` だけで試せる。
- APIキーやクラウド権限が不要になる。
- 静的ホスティングへ移せるが、デプロイと公開は別ゲートとする。
- 永続保存と複数人同時実行はMVP対象外になる。
