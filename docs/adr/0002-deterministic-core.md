# ADR-0002: 中核状態を決定論エンジンが所有する

- 状態: accepted
- 日付: 2026-08-24

## 文脈

LLMだけで長期社会シミュレーションを進めると、同じ条件でも結果が揺れ、物語の説得力と比較可能性を混同しやすい。

## 判断

年、予算、施策、能力、リスク、ストレステスト結果は純粋関数による決定論エンジンが所有する。描画、UI、将来の推論エージェントは状態の正本にしない。

## 帰結

- 同じ状態と施策から同じ結果を再現できる。
- 係数と評価関数をコードレビューできる。
- 将来LLMを加える場合は、提案・解釈・対話だけを担う交換可能なアダプターにする。
- 決定論であることは妥当性を保証しないため、係数の感度分析が別途必要になる。
