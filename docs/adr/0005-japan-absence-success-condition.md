# ADR-0005: 日本不在時の継続性を成功条件にする

- 状態: accepted
- 日付: 2026-08-24

## 文脈

日本の中心性、発言力、仲介回数を成功指標にすると、静かなオーケストレーターが新しい覇権や単一障害点へ変質する。

## 判断

2045年の主要成功条件を「日本が中心から退いても、協調ネットワークが機能する」にする。共同所有、代替経路、検証能力、国内正統性を能力として測り、権力集中、監視化、単一依存を同時に減点する。

## 帰結

- 日本への依存が高い成功は失敗として扱う。
- 制度を他主体へ移す行為がゲーム上の正の選択になる。
- 総合点だけでなく、能力とリスクの内訳を常に表示する。
- どの水準を「自律継続」と呼ぶかは、将来の感度分析と人間レビューが必要になる。
