# ADR-0012｜MVP実装範囲をM2〜M5とrun bundleへ拡大する

- status: accepted
- date: 2026-09-06
- 置換対象: ADR-0007の帰結「120ターンのイベント列はR4で追加する」、ADR-0008の帰結「全20接続への展開を次フェーズにする」、ADR-0009の「今日のMVP境界」

## 文脈

ADR-0007からADR-0009は、当時のMVP境界として次を記述していた。

- ADR-0007: 「MVPは期間、刻み、ターン数と集約結果を実装し、120ターンのイベント列はR4で追加する」
- ADR-0008: 「R1と旧R2の一部を統合し、全20接続への展開を次フェーズにする」
- ADR-0009: 「全20接続の校正、18主体の自律会話、120ターン危機、A〜E比較、日本除去実動、MPC最適化、RAGは含めない」

その後、これらの範囲外としていた項目のうち自律会話・MPC・RAGを除く全部が実装され、`main`へ統合された。範囲の変更は各PRのmergeとして人間が承認済みであり、ADR系列だけがその事実を記録していなかった。過去ADRを書き換えず、新しいADRから置換先を示すというこのディレクトリの規約に従い、この文書で範囲の現状を確定する。

## 判断

MVPの実装範囲を、代表接続1本の縦切りから次まで拡大したものとして記録する。

| 旧ADRが範囲外としていた項目 | 現状 | 実装 |
|---|---|---|
| 全20接続の校正 | 実装済み | `app/src/simulation.js`（校正の正本はADR-0011） |
| 18主体の制約と権限分離 | 実装済み | `app/src/ai/actor-governance.js` |
| 120ターン危機のイベント列 | 実装済み | `app/src/crisis.js` |
| A〜E比較・5真因seed・係数感度 | 実装済み | `app/src/experiments.js` |
| 日本ノード除去試験 | 実装済み | `app/src/experiments.js` |
| Cloud handoff用の実行bundle | 実装済み | `app/src/run-bundle.js`（ADR-0010） |
| 18主体の自律会話 | 未実装 | M6（AI説明層） |
| MPC最適化・RAG | 未実装 | 範囲外のまま |

## 置換しないもの

置換するのは上記3つのADRの**範囲記述**だけであり、判断本体は有効なまま維持する。

- ADR-0007の「危機試験は30日・6時間×120ターン」という設計は変更しない。
- ADR-0008の縦切り順序と代表接続の選定理由は変更しない。校正変更ゲートも有効である。
- ADR-0009の安全境界（Policy Engineは提案だけを返す、状態遷移は決定論コアが所有する、AI/LLM推論は未実装）は変更しない。

## 帰結

- ADR系列を読んだ評価者が、実装済み範囲を旧ADRの範囲記述から誤読しない。
- 危機試験のチェックポイント評価は重み付き集約、120ターンのイベント列は`app/src/crisis.js`の別経路という二重構造が現行実装である。両者を混同しない。
- 数値と係数は架空であり、範囲の拡大は研究上の妥当性や政策効果を意味しない。
- 残る境界は同一HEADのUI・アクセシビリティ証拠、M6、M7であり、順序は[ロードマップ](../../ROADMAP.md)が所有する。
