# ADR-0008｜接続投資から危機寄与までを縦切りで実装する

- status: accepted
- date: 2026-08-24

## 文脈

ADR-0006で、接続状態と因果レジャーを正本にすると決めた。従来のROADMAPは「全体指標の説明」と「接続状態化」を別フェーズにしていたため、最初のフェーズだけではユーザーの中心疑問である「誰と誰の接続が、なぜ変わり、何へ効いたか」へ答えられない。

また、20接続を一度に状態化すると、係数、UI、migration、テストの誤りを一括で抱える。

## 判断

最初の実装単位を、一つの代表接続に対する次の縦切りとする。

1. 年間施策と投資先を選ぶ。
2. 接続の変更前後、副作用、理由を予告する。
3. 決定論コアが接続状態を更新する。
4. 因果レジャーへ記録する。
5. 全体能力と危機結果が接続状態から再計算される。
6. UIから危機結果を接続の変更まで逆引きする。

この縦切りが再現可能になってから、同じschemaを全20接続へ広げる。

## 最初の代表接続

`B1 BRIDGE ↔ C6 中国・研究機関`の共同検証接続を使う。検証、翻訳、共同所有、依存、開示コストを同時に観測でき、軍事指揮を模倣せずに中心仮説を試せるためである。

実装時に特定国へ有利・不利な係数を固定せず、同じ制約型を別接続へ差し替えられるfixtureを併設する。

## 帰結

- 最短でプロダクトゴールを体験できる。
- 接続schema、レジャー、UI、危機寄与の境界を小さく検証できる。
- 最初の代表接続だけを作品全体の実証と誤認しない表示が必要になる。
- R1と旧R2の一部を統合し、全20接続への展開を次フェーズにする。

## 2026-08-24 採用追記

ユーザーの「推奨採用」を受け、代表接続の初期値、5施策の接続delta、危機寄与weight、現行UIの情報密度を、ハッカソン体験検証用の`relationship-v1.0.0`として採用する。正本と数値は[架空係数 Calibration v0](../calibration-v0.md)に置く。

許可するのは、架空・未校正を明示した決定論シミュレーションでの利用である。経験的確率、政策効果、実在組織の能力評価としての表示は許可しない。

係数を変更する場合は、次を同一変更で満たす。

1. `CALIBRATION_VERSION`を更新する。
2. 感度分析または利用者テストの変更理由を記録する。
3. 回帰テストとCalibration文書を更新する。
4. 結論を都合よく動かす変更でないことを人間レビューへ戻す。

公開リポジトリへのpush、PR、merge、告知は、この採用判断には含めない。

## 非採用

- 全体指標の差分表示だけを先に完成させる: 接続の因果を説明できない。
- 全20接続を同時に状態化する: schemaの誤りと係数の恣意性を早期に検出しにくい。
- LLMエージェントから先に追加する: 状態正本と反証可能性が未完成のため。
