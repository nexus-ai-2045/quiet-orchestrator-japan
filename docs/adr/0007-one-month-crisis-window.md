# ADR-0007: 危機試験を「終末の1ヶ月」にする

- 状態: accepted
- 日付: 2026-08-24
- 置換対象: ADR-0001の危機試験期間

## 文脈

72時間では初動の誤帰属と即応は観測できるが、静かなオーケストレーションが本当に支えるべき疲労、補給、復旧、世論、企業の継続判断、同盟調整、撤退経路の維持を十分に検査できない。

## 判断

入れ子の危機試験を30日間の「終末の1ヶ月」とする。1ターンは6時間、全120ターンとし、2030、2035、2040、2045年の節目で長期状態を固定して実行する。

## 帰結

- 初動だけでなく、制度と接続が長期化する圧力に耐えるかを検証する。
- テスト中に年次能力を成長させず、長期投資の状態を初期条件として固定する。
- MVPは期間、刻み、ターン数と集約結果を実装し、120ターンのイベント列はR4で追加する。
- 「終末」は作品上の危機の深さを示す名称であり、現実の戦争予測や破局の断定ではない。
