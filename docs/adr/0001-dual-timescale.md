# ADR-0001: 二重時間軸を採用する

- 状態: accepted
- 日付: 2026-08-24

## 文脈

初期案は南西諸島の72時間複合危機を本編としていた。しかし、日本が翻訳・検証・相互運用の基盤をつくる作用は、危機発生後の即応より10〜20年の制度形成にある。

## 判断

2026〜2045年を1年1ターンの本編とする。72時間危機は2030、2035、2040、2045年に長期投資を検査する入れ子のストレステストとする。

## 帰結

- プレイヤーは危機対応者ではなく、接続の設計者になる。
- 72時間の結果は、その時点までの能力・依存・正統性から導出する。
- 長期投資と危機時の結果を別々に検証できる。
- 年次モデルの較正根拠は今後必要であり、現在の係数を実確率と呼ばない。
