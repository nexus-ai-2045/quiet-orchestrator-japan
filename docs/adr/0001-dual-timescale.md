# ADR-0001: 二重時間軸を採用する

- 状態: accepted
- 日付: 2026-08-24

> 危機試験の期間は[ADR-0007](0007-one-month-crisis-window.md)で72時間から30日へ置き換えた。二重時間軸という判断自体は継続する。

## 文脈

初期案は南西諸島の72時間複合危機を本編としていた。しかし、日本が翻訳・検証・相互運用の基盤をつくる作用は、危機発生後の即応より10〜20年の制度形成にある。危機期間は後にADR-0007で30日間へ拡張した。

## 判断

2026〜2045年を1年1ターンの本編とする。30日間の危機試験は2030、2035、2040、2045年に長期投資を検査する入れ子のストレステストとする。

## 帰結

- プレイヤーは危機対応者ではなく、接続の設計者になる。
- 30日間の結果は、その時点までの能力・依存・正統性から導出する。
- 長期投資と危機時の結果を別々に検証できる。
- 年次モデルの較正根拠は今後必要であり、現在の係数を実確率と呼ばない。
