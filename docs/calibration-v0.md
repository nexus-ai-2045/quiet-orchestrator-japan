# 架空係数 Calibration v0

- version: `relationship-v1.0.0`
- status: 採用済み（ハッカソン体験検証用）
- adopted: 2026-08-24
- implementation SSOT: [`app/src/calibration-v0.js`](../app/src/calibration-v0.js)

## 位置づけ

この係数は、代表接続`B1 BRIDGE ↔ C6 中国・研究機関`について「年間投資が接続を変え、危機結果へ寄与する」という因果鎖を操作可能にするための架空値である。経験的確率、政策効果、実在組織の能力評価ではない。

### Principle

係数は結論を証明する値ではなく、仮説を反証できる体験を成立させる暫定パラメータとして使う。

### Invariant

- 国名だけを理由に係数を変えない。
- リスク側のdeltaを隠さない。
- 係数変更時はversion、ADR、回帰テストを同じ変更で更新する。
- 公開表示では架空・未校正であることを明示する。

### Detector

`app/tests/simulation.test.mjs`がversion、代表初期値、検証施策delta、改善方向、危機寄与weightを固定照合する。改善が全てclampされ逆効果だけが残る状態では施策を不適格にし、部分的な改善では集約効果を実現率で縮小する。因果台帳は実行時の`ruleVersion`とseedを保持する。

### Repair Path

係数を変える場合は、感度分析または利用者テストの証拠を添え、ADR-0008の追記または置換ADRを作成し、`CALIBRATION_VERSION`を更新する。結果だけを都合よく動かす変更は採用しない。

### Evidence

- unit testで同一seed・状態・施策から同一結果になることを確認する。
- UIで投資前delta、投資後before/after、危機寄与を逆引きできる。
- repo-preflightで公開差分のsecret候補・個人pathを検査する。

## 年間施策の接続delta

| 施策 | 接続delta | 明示する交換条件 |
|---|---|---|
| 翻訳 | 成熟度`+6`、信頼`+5`、相互運用`+2`、開示コスト`+1` | 開示コスト`+1` |
| 検証 | 成熟度`+5`、信頼`+4`、検証合意`+12`、単一依存`-1`、開示コスト`+2` | 開示コスト`+2`、監視化リスク`+2` |
| 可逆化 | 成熟度`+3`、相互運用`+4`、単一依存`-4`、代替経路`+1` | 合意形成速度を優先しない |
| 複線化 | 成熟度`+4`、相互運用`+7`、単一依存`-8`、代替経路`+1`、開示コスト`+1` | 開示コスト`+1`、維持経路が増える |
| 共同所有 | 成熟度`+4`、信頼`+3`、共同所有`+10`、単一依存`-5` | 日本の単独編集権を縮小 |

2038年以降は長期疲労として、`+2`以上の正方向deltaを`-1`する。代替経路の上限は5、その他の状態は0〜100へclampする。

集約効果の実現率は、施策が要求した改善方向deltaの絶対量を分母、clamp後に実現した改善方向deltaの絶対量を分子として算出する。成熟度・信頼・検証合意・相互運用・共同所有・代替経路は増加、単一依存・開示コストは減少を改善方向とする。逆方向deltaは実現量へ算入せず、集約効果は実現率を掛けて整数へ丸める。実現率が0なら施策は実行せず、年・予算・接続・集約metricを変更しない。

## 危機寄与selector

接続の現在値と初期値の差へ次のweightを掛け、四捨五入後に`-20〜+25`へclampする。

| 結果 | 正方向 | 負方向 |
|---|---|---|
| 誤帰属回避 | 検証合意`0.28`、信頼`0.14` | 開示コスト`-0.08` |
| 協調継続 | 成熟度`0.12`、相互運用`0.18`、共同所有`0.20`、代替経路`1.50` | 単一依存`-0.12` |
| 民間保護 | 相互運用`0.15`、信頼`0.10`、代替経路`1.20` | 単一依存`-0.12`、開示コスト`-0.05` |

## 人間レビュー境界

今回の採用は、ハッカソン用の架空係数v0として体験検証へ使う判断である。実証済み、政策推奨、将来予測として扱うことは許可しない。全20接続への展開、経験的校正、外部研究引用による係数変更、公開リポジトリへのpush・PR・mergeはそれぞれ別のレビュー境界とする。
