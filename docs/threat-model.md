# 脅威モデル

## 対象

ローカルで動く静的な社会シミュレーター、公開文書、依存パッケージ、将来の入力データを対象とする。現実の防衛・外交・重要インフラシステムではない。

## 保護するもの

- 公開情報、主張、推論、提案の区別
- 再現可能な状態遷移と評価係数
- 実在組織を将来予測として誤認させない境界
- コントリビューターの認証情報、個人情報、非公開パス
- 公開repositoryの供給網とビルド再現性

## 主な脅威と対策

| 脅威 | 影響 | MVPの対策 |
|---|---|---|
| 現実の攻撃帰属として引用される | 誤情報、外交・安全保障上の誤解 | 全画面と文書で架空・非公式を明示し、証拠型を分離 |
| 実在組織の能力・意図を断定する | 誤解、当事者への危害 | 公開役割を圧縮した論理主体だけを使用 |
| 秘密・個人情報を入力またはcommitする | 漏洩 | ライブ入力と外部APIを持たず、secret・personal path scanを公開ゲートにする |
| LLMが結果を都合よく変える | 再現性と公平性の喪失 | 中核状態を決定論エンジンが所有 |
| 係数に日本有利の価値判断を埋め込む | 結論先取り | 係数をコード化し、能力とリスクを分離、反証条件を公開 |
| 依存パッケージが侵害される | ブラウザ実行時のコード侵害 | lockfile固定、依存最小化、build/test、更新時レビュー |
| 外部送信やテレメトリが追加される | 閲覧・入力情報の流出 | MVPは通信なし。追加時はADR、脅威モデル更新、人間レビューを必須化 |

## 信頼境界

ブラウザ内の状態は信頼できる政策データではなく、ページ再読み込みで失われるデモ状態である。公式URLは根拠台帳でのみ扱い、実行時に取得しない。将来保存・共有・LLM連携を加える場合、この境界は再設計する。

## 対象外

- 現実の脆弱性探索、攻撃手順、標的選定
- 実運用の認証・認可・秘密管理
- 軍事・外交の意思決定支援としての安全性保証
